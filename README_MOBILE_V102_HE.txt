TripCraft Mobile V102 — גרסת פיילוט מלאה
=========================================

בסיס הגרסה
-----------
V102 נבנתה ישירות מעל V101 היציבה. קבצי V101 נשמרו ולא הוחלפו.

מה תוקן בגרסה זו
-----------------
1. כפתור "בנה טיול" מפעיל מסלול V102 יחיד: יצירה, הצגה, שמירה בענן וקישור קבוע.
2. בדמו נפתח 100% מהטיול. ההכנה העתידית למסלול בתשלום נשמרה כנתון של 20%, אך אינה נועלת דבר כעת.
3. כל יום כולל שעה, מקום, מה עושים, משך ביקור, זמן מעבר, מצב נהיגה/הליכה, Google Maps, Waze בנסיעה, עלויות וחלופה ליום גשום.
4. העלויות מחולקות למבוגר, ילד ו-Senior; כשאין מחיר אמין מופיע "מחיר אינו זמין — נדרשת בדיקה".
5. הטיול נשמר בטבלת tripcraft_trips עם Trip ID וקישור קבוע.
6. הקישור נוצר מהכתובת הציבורית של TripCraft גם אם פתחתם את הדמו מקובץ מקומי.
7. משתמש קיים עם טיולים מגיע ל"הטיולים שלי": שם, יעד, תאריכים, קישור, פתיחה ועריכה.
8. פתיחת טיול קיים מחזירה את כל נתוני השאלון. טיול חדש נפתח נקי, למעט ברירות המחדל; Tyrol אינו נשמר אוטומטית.
9. נוסף גיל Senior ‏(65+) לשאלון ולחישוב העלויות.
10. הלוגו שסופק מופיע בכותרת, באייקון הדפדפן ובאייקוני iPhone/Android. כל דפי הטיול מפנים לקובץ הלוגו המקומי.

פעולה חד-פעמית הכרחית ב-Supabase
--------------------------------
בלוג שסופק הופיע 404 עבור /rest/v1/tripcraft_trips. לכן לפני בדיקת השמירה יש:

1. להיכנס ל-Supabase.
2. לפתוח SQL Editor.
3. לפתוח את הקובץ SUPABASE_SETUP_V102.sql שנמצא בחבילה.
4. להעתיק את כולו, להריץ פעם אחת, ולוודא שהפעולה הסתיימה ללא שגיאה.

בלי הטבלה אין אפשרות לשמור טיול קבוע בבסיס הנתונים. V102 מציגה הודעה מדויקת אם שלב זה חסר.

בדיקה מומלצת
------------
1. להיכנס עם משתמש ו-OTP.
2. לבחור "בניית טיול חדש" ולוודא שהיעד ריק.
3. להשלים את השאלון וללחוץ "בנה טיול".
4. לוודא שמוצג כל הטיול, לפתוח יום ולבדוק את הפירוט וחלופת הגשם.
5. להעתיק את הקישור, לפתוח אותו ולהתחבר.
6. לחזור ל"הטיולים שלי", לפתוח את הטיול ולוודא שכל שדות השאלון התמלאו.
