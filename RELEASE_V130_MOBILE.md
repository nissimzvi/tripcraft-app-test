# TripCraft MOBILE V130

Focus: day-level execution reliability.

- Robust delegated "Open day details" action; no dependency on brittle inline onclick.
- Full day drill-down: date, summary, overnight location, full Google Maps route, timed stops, descriptions, notes, costs, Google Maps + Waze per stop.
- Day-level TripCheck findings shown when available.
- Live rainy-day alternative generated on demand by TripCraft AI V130 using web search, with sources, times, routing, Maps/Waze, notes and optional replace-day action.
- Rain alternative and its AI usage are persisted with the trip.
- Mobile day modal made full-screen on small screens for reliable interaction.
