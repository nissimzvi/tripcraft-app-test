TripCraft V4.30 — מבוסס ישירות על V4.29.

שינויים בלבד:
- עיצוב, ניווט, טיולים, Planner ו-Drill Down של V4.29 נשמרו.
- במסך ניהול נוסף אזור "חיבור AI — מצב ניסוי".
- אפשר להדביק API Key פעם אחת ולשמור אותו מקומית בדפדפן (localStorage).
- המפתח אינו כתוב בקוד ואינו נמצא ב-ZIP.
- מוצג רק מפתח מוסווה.
- אפשר למחוק את המפתח.
- "בדוק חיבור" בשלב זה הוא בדיקת מוכנות מקומית בלבד ואינו שולח בקשה ל-OpenAI, ולכן אינו צורך קרדיט.
- המערכת ממשיכה לעבוד במצב Demo ללא API.

אבטחה:
גרסה זו מיועדת לניסוי מקומי בלבד. לפני פרסום ללקוחות אין לשמור API Key בדפדפן; יש להעביר אותו ל-Backend/Secret מאובטח.
