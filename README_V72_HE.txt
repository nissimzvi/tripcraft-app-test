TripCraft V72 — מבוסס ישירות על V70 היציבה

עיקרי השינויים:
- PWA רספונסיבי: iPhone, Android ומחשב. כולל manifest, Service Worker ואייקונים.
- אשף תכנון מחולק ל-16 מסכים קצרים, עם Next / Back, ללא גלילת עמוד במסכי המובייל.
- שלבים נפרדים ליעד, שדות תעופה ותאריכים כדי לשמור על שדות רחבים ונוחים.
- בחירת יום מלא / חצי יום / גמיש.
- תכנון לפי מקומות הלינה: כל יום מעוגן בלינה, כולל טיולי כוכב ומעבר בין מלונות.
- מלונות קיימים: הזנה בעברית או באנגלית, הוספת מספר מקומות לינה והשלמה אוטומטית.
- תיקון חיפוש שויץ / שוויץ / שווייץ / Switzerland בשדות שדה התעופה (ZRH/GVA).
- הוספת Tyrol / Tirol / טירול כחיפוש אזור מקומי.
- הרשמת פיילוט בסוף התכנון, רגע לפני יצירת הטיול. שם ואימייל חובה; טלפון אופציונלי.
- הסבר מפורש שהפרטים נאספים לצורך שמירת הטיול, עדכונים וקבלת פידבק/משוב בפיילוט.
- פיילוט: הכנה למגבלה של עד 10 שינויים לטיול.
- Booking: נשמרת תשתית Partner/Affiliate ID שאינה סודית. API Secret לא נשמר ב-GitHub ויעבור לשרת מאובטח.
- לוגו TripCraft בדף הראשי מחזיר ל-Home ללא טעינה מיותרת.
- V70 נשארת נקודת החזרה היציבה ואינה משתנה.

הערה חשובה לפיילוט ציבורי:
מסך ההרשמה ומונה השינויים קיימים כעת בממשק, אך מעקב מרכזי אמיתי אחרי משתמשים/שינויים ואבטחת API דורשים Backend/Database. אין להכניס API keys או סודות לקוד הסטטי.
