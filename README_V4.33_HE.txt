TripCraft V4.33 — Business Flow Prototype

בסיס: V4.31 שעבדה ונשמרה ללא שינוי.

נוסף:
- 6 טיולים קבועים בכרטיסים עם 6 תמונות שונות.
- דף מחירים נפרד.
- סל וקופה Demo.
- הרשמה חד-פעמית + OTP בן 6 ספרות לטלפון/מייל (Demo מציג את הקוד).

- רישום תשלום מצליח/נכשל וחיפוש Admin.

- Admin מוסתר מלקוחות. בגרסת הקובץ המקומית בלבד ניתן להפעיל Admin ע״י ?admin=1. זה אינו מנגנון אבטחה לפרודקשן.
- עברית/אנגלית ו-RTL/LTR.
- תפריט המבורגר מימין במובייל.
- דף בית בלבד בכניסה; כל אזור נפתח כדף נפרד דרך Hash.
- פרטיות/תקנון/נגישות כנוסחי פיתוח.

חשוב: אבטחה אמיתית, OTP אמיתי, תשלומים אמיתיים, מסד נתונים והרשאות Admin מחייבים Backend. GitHub Pages ישמש Frontend בלבד.
