TripCraft Mobile V111 — התחלה מהירה

1. חלצו את קובץ ה-ZIP. כל הקבצים נמצאים בתוך התיקייה TripCraft_Mobile_V111.
2. העלו את תוכן התיקייה לשורש מאגר GitHub Pages.
3. ודאו שכל הקבצים, ובפרט tripcraft-v111.js, נמצאים ליד index.html.
4. לאחר הפרסום ודאו שבכותרת מופיע V111.
5. באייפון רעננו את האתר פעם אחת כדי שמטמון V111 החדש יחליף את V110.

פירוט השינויים והבדיקות נמצא בקובץ RELEASE_V111_MOBILE.md.
